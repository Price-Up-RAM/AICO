AICO 개인정보처리방침

AICO(이하 '앱')는 사용자의 개인정보 보호를 중요하게 생각하며, 「개인정보 보호법」, 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 등 관련 법령을 준수합니다. 본 방침은 앱이 어떤 정보를 처리하고, 그 정보가 어디로 전송되며, 어떻게 보관·파기되는지를 설명합니다.

1. 처리하는 정보의 항목 및 수집 방법

앱은 회원가입이나 계정 시스템을 운영하지 않으며, 이름·연락처·이메일·전화번호·광고 식별자 등 사용자를 특정할 수 있는 식별 정보를 수집하지 않습니다. 앱이 처리하는 정보는 다음과 같습니다.

  • 음성 데이터: 사용자가 음성 입력 버튼을 눌러 발화한 구간의 녹음이 음성 인식(STT)을 위해 처리됩니다. 사용자가 음성 입력을 시작하지 않으면 녹음하지 않으며, 상시 청취(always-listening)는 수행하지 않습니다.
  • 화면 캡처 이미지: 사용자가 「이미지 사용」 기능을 켜고 화면 캡처를 승인한 경우에 한해, 선택한 화면 영역의 이미지가 처리됩니다. 이 기능은 기본값이 꺼짐(off)이며, 사용자가 직접 켜야 동작합니다.
  • 대화 텍스트: 사용자가 앱에 입력하거나 음성으로 전달한 질의 내용과 AI 응답입니다.
  • 앱 설정값: 캐릭터 호칭, 표시 언어, 음량, 캐릭터 크기, 연결할 서버 주소·서버 ID, 화면 캡처 영역 좌표 등 사용자가 선택한 설정입니다.
  • 진단 로그: 오류 원인 파악을 위한 서비스 상태 기록으로, 기기 내부에만 저장됩니다.

앱이 사용하는 기기 권한과 그 목적은 다음과 같습니다. 각 권한은 아래 명시된 목적 외로 사용되지 않습니다.

권한사용 목적
마이크 녹음
(RECORD_AUDIO, FOREGROUND_SERVICE_MICROPHONE)		 사용자가 음성 입력을 실행한 구간의 음성을 텍스트로 변환하기 위해 사용합니다.
화면 캡처
(MediaProjection, FOREGROUND_SERVICE_MEDIA_PROJECTION)		 사용자가 시스템 확인 창에서 캡처를 승인한 경우에만, 화면 이미지를 일시적으로 가져오기 위해 사용합니다. Android가 캡처 중임을 상태 표시로 알립니다.
다른 앱 위에 표시
(SYSTEM_ALERT_WINDOW)		 캐릭터와 대화 인터페이스를 다른 앱 위에 겹쳐 표시하기 위해 사용합니다. 이 권한은 화면 내용을 읽거나 캡처하는 기능이 아닙니다.
포그라운드 서비스 / 알림
(FOREGROUND_SERVICE, FOREGROUND_SERVICE_SPECIAL_USE, POST_NOTIFICATIONS)		 캐릭터 오버레이가 종료되지 않도록 상주 서비스를 유지하고, 실행 상태 알림을 표시하기 위해 사용합니다.
인터넷 접속
(INTERNET)		 AI 응답 생성, 음성 인식, 음성 합성을 위해 서버와 통신하기 위해 사용합니다.

2. 처리 목적

  • 음성 데이터: 음성을 텍스트로 변환(STT)하여 사용자의 질의로 전달
  • 화면 캡처 이미지: 사용자가 요청한 질문에 대해 현재 화면 맥락을 반영한 답변 생성
  • 대화 텍스트: AI 응답 생성 및 직전 대화 맥락 유지
  • 앱 설정값: 사용자가 선택한 동작·표시 상태를 재실행 시에도 유지
  • 진단 로그: 오류 진단 및 기능 정상 동작 확인

앱은 위 정보를 광고, 마케팅, 프로파일링, 이용자 식별, 제3자 판매 목적으로 이용하지 않습니다.

3. 접근성 서비스 이용 안내

앱은 「AICO 터치 안정화」라는 이름의 선택적 접근성 서비스를 제공합니다. 이 서비스를 켜지 않아도 앱의 모든 기능을 사용할 수 있습니다.

  • 사용 목적: 접근성 오버레이 창을 이용해 캐릭터 창의 떨림을 줄이고, 캐릭터 뒤에 있는 앱으로 전달되는 터치 영역을 안정적으로 유지하기 위한 화면 표시 품질 개선 용도로만 사용합니다.
  • 읽지 않는 정보: 이 서비스는 화면에 표시된 텍스트나 화면 구성 요소를 조회하지 않습니다. 앱은 화면 내용 조회 권한을 사용하지 않도록 설정되어 있으며 (canRetrieveWindowContent="false"), 접근성 이벤트의 내용을 읽거나 저장하지 않습니다.
  • 수행하지 않는 동작: 사용자의 입력 내용(키 입력·비밀번호 등) 수집, 제스처 실행, 다른 앱의 자동 조작, 화면 캡처를 일절 수행하지 않습니다.
  • 수집·전송 여부: 접근성 서비스를 통해 취득하는 개인정보가 없으므로, 이를 저장하거나 서버·외부 AI 서비스로 전송하는 일도 없습니다.
  • 동의 및 해제: 접근성 서비스는 사용자가 앱 내 고지 화면에서 내용을 확인하고 동의한 뒤, Android 설정에서 직접 켜야만 활성화됩니다. 언제든지 기기 설정 → 접근성 → 설치된 앱/서비스에서 끌 수 있으며, 끄면 앱은 일반 오버레이 방식으로 계속 동작합니다.

4. 데이터가 전송되는 곳

앱이 처리하는 정보의 목적지는 다음 세 가지로 구분되며, 사용자의 설정에 따라 달라집니다.

A. 사용자 기기 내부 (외부로 전송되지 않음)

  • 앱 설정값과 진단 로그는 다른 앱이 접근할 수 없는 앱 전용 내부 저장 영역에 저장됩니다.
  • 화면 캡처 이미지는 전송 목적의 임시 파일로만 기기에 기록되며, 앱 전용 저장 영역을 벗어나지 않습니다.

B. 사용자가 직접 운영하는 AICO 서버 (AI 처리용)

AI 응답 생성, 음성 인식, 음성 합성 연산은 기기에서 수행하지 않고 별도의 AICO 서버에서 수행합니다. 이 서버는 개발자가 운영하는 서비스가 아니라, 사용자가 자신의 PC에 직접 설치하고 실행하는 프로그램입니다. 따라서 다음 정보가 사용자 본인의 PC로 전송되며, 개발자는 이 데이터를 수신하거나 열람하지 않습니다.

전송되는 정보목적전송 조건
음성 녹음 파일 음성 인식(STT), 화자 구분 사용자가 음성 입력을 실행한 경우
대화 텍스트, 직전 대화 맥락, 캐릭터 호칭·언어 설정 AI 응답 생성, 음성 합성 사용자가 대화를 전송한 경우
화면 캡처 이미지 화면 맥락을 반영한 답변 생성 사용자가 「이미지 사용」을 직접 켜고 캡처를 승인한 경우에만 (기본값 꺼짐)

앱은 다음 순서로 접속할 서버를 찾습니다. 어느 경로가 사용되는지는 사용자의 설정에 따라 결정됩니다.

  • 사용자가 입력한 서버 주소: 앱 설정에 주소를 직접 입력한 경우 해당 주소로 전송됩니다.
  • 같은 기기 / USB 직결: 사용자가 자신의 PC를 기기와 직접 연결한 경우 로컬 주소로 전송됩니다. 이 구간은 암호화되지 않은 HTTP 통신을 사용하지만, 기기 외부 네트워크로 나가지 않습니다.
  • 사용자의 서버 ID를 통한 터널 접속: 위 경로가 없을 경우, 사용자가 앱 설정에 입력한 서버 ID로 https://{서버ID}.60000123.xyz 주소를 조립해 접속합니다. 이는 사용자가 자신의 PC에서 실행한 서버를 외부에서 접속할 수 있도록 터널로 연결하는 방식이며, 연결 대상은 해당 서버 ID를 등록한 사용자 본인의 PC입니다. 통신은 HTTPS로 암호화됩니다.

개발자는 대화 내용을 처리하거나 저장하는 서버를 운영하지 않습니다. 다만 위 터널 주소로의 접속을 사용자 본인의 PC로 연결해 주기 위해, 개발자가 60000123.xyz 도메인과 Cloudflare Workers 기반 중계 구성을 관리합니다. 이 구성은 요청을 올바른 대상 PC로 연결하는 경로 설정 역할만 수행하며, 음성·대화·이미지 등 전송 내용을 저장하거나 별도로 수집하지 않습니다. 네트워크 중계 과정에서 데이터는 Cloudflare의 인프라를 경유합니다.

서버로 전송되는 요청에는 로그인 정보나 기기 고유 식별자가 포함되지 않습니다. 전송된 데이터의 보관·삭제는 해당 PC를 관리하는 사용자 본인의 통제 하에 있으며, 개발자는 이 데이터를 보관하지 않습니다.

주의: 앱 설정의 서버 ID는 반드시 사용자 본인이 운영하는 서버의 ID로 지정해야 합니다. 타인의 서버 ID를 입력하면 음성·대화·화면 이미지가 해당 서버의 운영자에게 전송됩니다.

C. 외부 AI 제공사

AI 응답 생성·번역·웹 검색을 위해, B의 서버(= 사용자 본인의 PC)가 아래 외부 AI 서비스로 필요한 데이터를 전달할 수 있습니다. 이 호출은 사용자 본인의 PC에서 사용자 본인의 계정·API 키로 이루어지며, 개발자를 경유하지 않습니다. 전달 여부와 대상은 사용자가 서버에서 선택한 AI 모델 설정에 따라 결정되고, 서버를 로컬 AI 모델만 사용하도록 구성한 경우 외부로 전달되는 데이터가 없습니다.

제공받는 자전달되는 정보목적
Google (Gemini API, 웹 검색) 질의 텍스트, 사용자가 이미지 사용을 켠 경우 화면 캡처 이미지 AI 응답 생성, 웹 검색 결과 반환
OpenRouter 질의 텍스트 AI 응답 생성. OpenRouter는 사용자가 선택한 모델의 원 제공사(OpenAI 등)로 요청을 다시 전달합니다.
DeepL 번역 대상 텍스트 텍스트 번역
  • 이전되는 국가: 미국 등 (해당 서비스의 서버 소재지에 따름)
  • 보유 및 이용 기간: 각 제공사의 개인정보처리방침 및 요금제에 따릅니다. Google Gemini API의 경우 무료로 제공되는 서비스와 유료 서비스의 데이터 취급 방식이 다르며, 무료 서비스에서는 입력 데이터가 모델 품질 개선에 이용될 수 있습니다. 사용자가 어떤 유형을 이용하는지에 따라 취급이 달라지므로, 이용 전 각 제공사의 방침을 확인하시기 바랍니다.

5. 보관 및 파기

  • 기기 내 데이터: 앱 설정값, 진단 로그, 화면 캡처 임시 파일은 앱 전용 저장 영역에 보관됩니다. 기기 설정 → 애플리케이션 → AICO → 저장공간 → 데이터 삭제를 실행하거나 앱을 삭제하면 모두 즉시 파기됩니다.
  • 대화 맥락: 직전 대화 맥락은 대화 세션 유지 목적으로만 사용되며, 별도의 이용자 프로필로 축적되지 않습니다.
  • 서버로 전송된 데이터: 서버는 사용자가 자신의 PC에서 운영하는 프로그램이므로, 전송된 데이터의 보관 기간과 삭제 시점은 해당 PC를 관리하는 사용자 본인이 결정합니다. 개발자는 이 데이터를 보관하지 않으며 접근할 수단도 갖지 않습니다.
  • 외부 AI 제공사로 전달된 데이터: 해당 제공사의 방침에 따라 처리됩니다.

6. 개인정보의 제3자 제공 및 국외 이전

앱은 사용자의 정보를 판매하거나 광고·마케팅 목적으로 제3자에게 제공하지 않습니다. AI 기능 수행에 필요한 범위에서 4항 C에 명시된 서비스로만 데이터가 이전되며, 각 항목의 전달 정보·목적·이전 국가는 4항 C의 표에 기재된 내용과 같습니다.

7. 안전성 확보 조치

  • 앱 설정과 로그는 다른 앱이 읽을 수 없는 앱 전용 내부 저장 영역에 보관합니다.
  • 앱은 개발자가 운영하는 데이터 수집·저장 서버를 두지 않습니다. AI 처리는 사용자 본인의 PC에서 이루어지며, 개발자는 대화 내용을 보관하지 않습니다. 터널 연결을 위한 중계 구성은 경로 설정 역할만 수행합니다(4항 B 참조).
  • 서버 ID를 통한 터널 접속은 HTTPS로 암호화합니다. 사용자가 로컬 주소나 사설 IP를 직접 입력해 연결하는 경우 해당 구간은 암호화되지 않은 HTTP를 사용하므로, 신뢰할 수 있는 네트워크에서만 이용하시기 바랍니다.
  • 화면 캡처와 마이크 사용 중에는 Android가 제공하는 상태 표시를 통해 동작 사실을 사용자가 확인할 수 있습니다.

8. 이용자의 권리 및 통제 수단

사용자는 다음 방법으로 언제든지 데이터 처리를 통제할 수 있습니다.

  • 권한 철회: 기기 설정 → 애플리케이션 → AICO → 권한에서 마이크, 알림 등의 권한을 철회할 수 있습니다. 「다른 앱 위에 표시」는 특별한 앱 액세스에서 철회할 수 있습니다.
  • 화면 캡처 중단: 앱 설정의 「이미지 사용」을 꺼서 화면 이미지 전송을 중단할 수 있습니다(기본값 꺼짐). 진행 중인 캡처는 알림에서 중단할 수 있습니다.
  • 접근성 서비스 해제: 기기 설정 → 접근성에서 언제든지 끌 수 있습니다(3항 참조).
  • 전송 대상 서버 확인·변경: 앱 설정의 서버 ID 또는 서버 주소로 전송 대상을 직접 지정할 수 있습니다. 본인이 운영하는 서버만 지정하면 데이터가 제3자에게 전송되지 않습니다.
  • 데이터 삭제: 앱 삭제 또는 기기 설정의 데이터 삭제로 기기 내 모든 데이터를 파기할 수 있습니다.
