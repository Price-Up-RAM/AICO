# 🌙 AICO — 당신의 데스크톱에 살고 있는 AI 컴패니언

화면 위에 항상 함께 있는 AI 캐릭터 어시스턴트 — 대화하고, 먼저 말을 걸고, 업무를 도와드립니다.

## 📌 AICO — 배경

AI 어시스턴트는 많지만, 대부분은 채팅창 속의 텍스트일 뿐입니다.
필요할 때만 열어보는 도구가 아니라, **곁에 있어 주는 존재**라면 어떨까요?

AICO는 1인 1비서를 목표로 당신의 하루에 자연스럽게 스며드는 것을 목표로 합니다.
일하다 지칠 때쯤 먼저 말을 걸어 주고, 부탁하면 대신 손을 움직여 주는 "도구"가 아닌 "동료"로서의 AI를 지향합니다.

## 💜 AICO — 개요

**AICO**는 Windows 데스크톱 위에 항상 떠 있는(투명 창 · 최상위 오버레이)
**AI 캐릭터 컴패니언**입니다.

- 오리지널 캐릭터 **AICO**가 화면 위에서 당신과 함께 지냅니다.
- 텍스트 채팅은 물론 **음성** 으로 대화하면, 감정이 담긴 표정에 목소리를 담아 답변해줍니다.
- **멀티모달 AI** — 텍스트만이 아니라 화면과 이미지를 함께 보고 이해하므로,
  지금 보고 있는 화면을 참고한 답변이 가능합니다.
- **에이전트 기능**을 통해 문서 정리, 화면 속 글자 읽기, 프로그램 실행, TODO 관리까지 —
  AI가 곁에서 당신의 업무를 돕습니다.
- **생활정보 브리핑** — 날씨, 문 연 약국, 공휴일 같은 생활 정보를 공공데이터에서 조회해
  캐릭터가 직접 알려줍니다.
- **완전 무료의 로컬 AI 지원** — 구독료와 API 요금이 드는 클라우드 AI와 달리, AICO는 내 PC에서
  직접 구동되는 로컬 AI로 동작합니다. 일반적인 PC 사양이면 충분하고, 비용 걱정 없이,
  대화 내용이 밖으로 나가지도 않습니다.

> 무엇이 추가되든 — **내 PC에서, 무료로, 내 데이터는 내 것** — 이 기본은 바뀌지 않습니다.

## ✨ 주요 기능

### 🗨️ 대화 — 기다리지 않는 AI

- 텍스트 채팅과 **음성 대화**(로컬 Whisper STT + TTS, VAD 자동 감지)를 모두 지원합니다.
- **선톡(SmallTalk)** — 일정 시간 조작이 없으면 캐릭터가 먼저 말을 겁니다.
- 대화 의도 파악(intent), **웹 검색 연동**, 생각(thinking) 표시, 감정 표현을 지원합니다.
- **화면 · 이미지를 참고한 답변(멀티모달)** — 스크린샷 영역을 지정해 두면 AI가 그 화면을 보고 답합니다.
- 답변 언어와 UI 언어를 각각 설정할 수 있습니다 (**한국어 / 日本語 / English**).

### 🤖 에이전트 — 말만 하면 업무를 돕는 AI

- 프로그램 실행, 클립보드 정리, 화면 캡처와 글자 인식(OCR) 등 자잘한 업무를 대신 처리합니다.
- TODO 추가 · 완료 · 조회로 할 일을 함께 관리하고, 필요한 정보를 저장해 두었다가 찾아 줍니다.
- **AI Skills** — 자주 쓰는 작업 절차를 마크다운 스킬로 저장하면 AI가 학습된 절차대로 수행합니다.
  스킬은 켜고 끄거나 커스텀 버전으로 덮어쓸 수 있습니다.

### 🌤️ 생활정보 브리핑 — 공공데이터 연동

- *"오늘 날씨 어때?"*, *"지금 문 연 약국 있어?"* 처럼 물어보면 AI가 **공공데이터포털 공식 API**를
  조회해 캐릭터의 목소리로 알려줍니다.
- 제공 정보 : **날씨 브리핑 · 기상특보 · 외출 신호등**, **지금 문 연 약국**, **의약품 안전 정보**(병용금기 안내),
  **공휴일 · 기한 D-day**, **복지 혜택 검색**, 음력 달력 · 무인민원발급기 안내 등 12종.
- 공공 API의 무료 키 기반이라 "완전 무료" 원칙은 그대로입니다.

### 🎭 대화 모드

- **Chat** — 캐릭터와의 기본 1:1 대화
- **Pomodoro** — 캐릭터가 옆에 앉아 함께하는 집중 타이머 모드

### 🎁 캐릭터와의 생활

- 캐릭터 드래그 · 쓰다듬기 · 볼 꼬집기 등 터치 인터랙션과 물리 반응

## 🛠 주요 기술

- **클라이언트** : Unity 6
- **AI 백엔드** : 로컬 AI 서버(Flask, `localhost:5000`)
  — 스트리밍 응답, 멀티모달(비전), 에이전트 함수 호출, OCR(PaddleOCR)
- **음성** : Whisper(로컬 STT), VAD, TTS
- **생활정보** : 공공데이터포털(data.go.kr) Open API — 기상청 · 식약처 · 한국천문연구원 등

## 📁 폴더 구성

다운로드한 폴더에서 기억해 둘 것은 사실상 두 가지뿐입니다.

```
AICO/
├─ AICO.exe        # 실행 파일 — 아이코 시작
├─ install.bat     # 로컬 AI 설치 (최초 1회)
├─ installer/      # 로컬 AI 설치기 구성 요소
├─ AICO_Data/      # 앱 리소스
└─ ...             # 그 외 구동용 파일 (건드리지 않아도 됩니다)
```

## 🚀 How to Use

### 1. 설치 — 최초 1회

- 최초 실행 전, **`install.bat`을 실행**하면 로컬 AI(서버 + AI 모델)가 자동으로 설치됩니다.
- 앱을 먼저 실행했다면 우클릭 메뉴의 **로컬 AI 설치**로도 설치할 수 있습니다.
- 이후로는 별도 설치 없이 앱만 실행하면 됩니다.

### 2. 실행

- **`AICO.exe`를 실행**하면 캐릭터가 데스크톱 위에 나타나고, 시스템 트레이에 아이콘이 등록됩니다.
- 로컬 AI 서버가 자동으로 함께 기동됩니다 — API 키도, 구독료도 필요 없이
  내 PC에서 완전 로컬로 동작하며, CPU / GPU 모드를 설정에서 선택할 수 있습니다.

### 3. 기본 조작

| 조작 | 동작 |
|---|---|
| **좌클릭** | 말 걸기 (채팅 풍선 열기) |
| **우클릭** | 메뉴 열기 |
| 좌클릭 길게(0.5초) · 더블클릭 | 메뉴 열기 (우클릭과 동일) |
| **드래그** | 캐릭터 옮기기 · 머리를 문지르면 쓰다듬기 |
| 트레이 아이콘 더블클릭 | 창 표시 / 숨기기 |

우클릭 메뉴 구성 :
**Settings**(설정) · **Character Detail**(캐릭터 상세 · 목소리 선택) · **Action**(원형 액션 메뉴 — 춤 · 이동) ·
**Chat**(New Chat · Chat History · Idle Talk) · **Mode**(Chat / Pomodoro) ·
**Control**(음성 입력 패널 · 자막 토글 · 스크린샷 영역 설정) · **Exit**

### 4. 첫 설정

- **Settings**에서 이름(호칭), UI 언어(ko/jp/en), 답변 언어, 음성 볼륨을 정합니다.
- **Character Detail**에서 AICO의 프로필을 보고 목소리를 고를 수 있습니다.
- 항상 위 표시, 캐릭터 크기 · 이동 속도 · 중력, 선톡 주기 등도 취향대로 조정할 수 있습니다.

### 5. 대화하기

- 캐릭터를 **좌클릭**해 채팅 풍선에 메시지를 입력하거나, **마이크 버튼 / VAD**로 음성 대화를 시작합니다.
- 웹 검색, 화면 이미지 인식(멀티모달), 생각 모드 등의 옵션을 켜면 답변에 활용됩니다.
- 가만히 두면 캐릭터가 먼저 말을 걸어옵니다
  (선톡 — 주기 조절 · 끄기 가능, 메뉴의 **Idle Talk**로 즉시 불러올 수도 있습니다).

### 6. 업무 · 생활 부탁하기 (에이전트)

- 대화로 그냥 부탁하세요 — *"메모장 열어서 회의록 정리해 줘"*, *"이 화면 캡처해서 글자 읽어 줘"*,
  *"할 일에 '보고서 제출' 추가해 줘"* 처럼 말하면 AI가 알맞은 방법을 스스로 골라 도와줍니다.
- *"오늘 날씨 어때?"*, *"지금 문 연 약국 찾아줘"*, *"다음 공휴일까지 며칠 남았어?"* 같은
  생활 정보도 공공데이터에서 바로 찾아 알려줍니다.
- 반복 작업은 **스킬로 저장**해 두면 다음부터 절차대로 수행합니다.

### 7. 모드 바꿔가며 지내기

- 집중이 필요하면 **Pomodoro 모드** — 캐릭터가 옆에 앉아 타이머가 끝날 때까지 함께합니다.
- 전역 단축키(F9~F12, 커스터마이징 가능)로 주요 기능을 어디서든 호출할 수 있습니다.

## ⚙️ 요구 사항

**일반적인 PC 사양이면 충분합니다** — 로컬 AI라고 해서 고성능 워크스테이션이 필요하지 않습니다.

- **OS** : Windows (투명 오버레이 · 트레이 · 전역 입력 등 Win32 기능 사용)
- **저장 공간** : 17GB + AI 모델 용량 (SSD 권장)

### 로컬 AI (완전 무료)

| 구분 | 사양 |
|---|---|
| **최소** | GPU 사용 시 VRAM 8GB / RAM 16GB 이상 (AI 모델별 상이) |
| **권장** | GPU VRAM 16GB |
| **CPU 전용** | GPU 없이도 구동 가능 — 답변 속도 저하만 감수한다면! |
