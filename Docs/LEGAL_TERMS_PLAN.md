# AICO 약관·법정 문서 방향 (조사 기준일: 2026-07-22)

배포 목적: 대한민국+글로벌 / 스팀 / 구글플레이 / 수익화 검토.
웹 조사(7개 축, 법적 의무·시행일은 별도 팩트체크 검증) + 코드 데이터 흐름 스캔 결과를 종합한 방향 문서.

## 0. 결론 요약

- 작성할 문서는 **무료 배포 단계 5종 + 수익화 단계 1종**이다 (아래 2절).
- 단, 약관 작성보다 먼저 결정해야 할 **전제조건 3가지**가 있다 (아래 1절).
  이 결정에 따라 약관에 들어갈 내용 자체가 달라진다.
- 한국은 실제로 약관 인프라가 좋다: 공정위 표준약관(모바일게임 제10078호, 2024-02-23 개정)과
  개인정보위 처리방침 작성지침(2025-04)을 골격으로 쓸 수 있다. 다만 AI 어시스턴트 특화 조항
  (에이전트 행위 면책, AI 출력 무보증, AI기본법 고지)은 표준약관에 없어 자체 추가해야 한다.

## 1. 약관 이전의 전제조건 3가지 (결정 필요)

### 1-1. 캐릭터 IP — 수익화의 최대 블로커 [2026-07-22 결정: 해소]

> **결정**: 수익화(product) 빌드에는 VRoid로 제작한 오리지널 AICO 캐릭터만 탑재. arona 등
> BA 유래 모델은 product 판에 미포함. → 아래 리스크는 product 판에 한해 해소.
> 잔여 주의: ① 스토어 페이지·스크린샷·홍보물에도 BA 캐릭터 노출 금지(그 자체가 침해),
> ② arona가 남는 무료/개인용 빌드를 공개 배포할 경우 넥슨 가이드상 여전히 개별 문의 대상,
> ③ AICO 캐릭터의 TTS 보이스 출처 검증(1-1절 말미)은 캐릭터와 무관하게 여전히 필요.

아로나·플라나(블루 아카이브) 유래 모델이 포함된 빌드는 **어떤 형태로든 스토어 수익화 배포 불가**가
현행 가이드라인상 결론이다.

- 넥슨 「게임IP 사용 가이드」(2024-09-13 공시, m.nexon.com/terms/743): UGC 유료 판매·대가 수취 금지.
  나아가 **게임IP로 게임을 제작·배포·서비스하는 것 자체가 원칙적 불허**이며, 비영리 앱조차
  고객센터 개별 문의(사전 허락) 대상. 위반 시 허락 즉시 취소.
- 일본 공식 가이드라인(bluearchive.jp/fankit/guidelines): 개인·비영리·**일본 국내 유통** 3중 제한.
  스팀/구글플레이 글로벌 배포는 지역 요건만으로도 이탈.
- 게임 클라이언트 추출(리핑) 에셋이면 **비영리 무료 배포도 위반**. 탑재 모델의 출처
  (추출본/팬제작/자체제작) 확인·기록이 선행 과제.
- 플랫폼 리스크 별도: 구글플레이는 IP 위반 시 개발자 계정 해지까지 가능, 스팀은 권리 보증 조항 위반.

선택지:
1. **(권장) 수익화 빌드에서 BA 유래 모델·명칭·이미지 전면 제거, 오리지널 캐릭터로 교체.**
   이름만 바꾸고 외형 유지는 회피가 안 됨(실질적 유사성 기준). 스토어 스크린샷·설명도 포함.
2. 캐릭터 미번들 + 사용자 모델 임포트(VRM) 구조 — 단 홍보물에 BA 캐릭터 노출 금지,
   약관에 사용자 콘텐츠 책임·권리침해 신고 처리 조항 필수.
3. 넥슨 서면 라이선스 협의(help.nexon.com) — 개인 대상 성사 사례 미확인, 기대치 낮게.

TTS 음성도 동일 축이다: 특정 성우·캐릭터 보이스를 학습·모방한 음성 모델이면 모델 교체와 별개로
퍼블리시티권 리스크(부정경쟁방지법 (파)목)가 남는다. 보이스 출처·상업 이용 가능 여부 전수 검증 필요.

### 1-2. 데이터 경로 — "완전 로컬"은 현재 코드와 모순

코드 스캔 결과, 출고 상태에서 이미 데이터가 사용자 기기를 떠나는 경로가 기본 탑재돼 있다:

| 경로 | 근거 | 나가는 데이터 |
|---|---|---|
| 하드코딩 무료 Gemini 키로 직결 | `ApiKei.cs:9-18`, `ApiGeminiDirectClient.cs:159` | 대화·이미지 → Google |
| 로컬 서버 미가동 시 원격 폴백 | `ServerManager.cs:121,207-224` (Supabase 등록 터널 URL) | 대화 전체 |
| 클라우드 LLM 라우팅 | 서버 `server_interface.py:506-760` (Gemini/OpenRouter/OpenAI) | 대화·memory 전체·이미지 |
| 웹검색 | `ai_web_search_module.py` (DuckDuckGo/Google CSE/Serper/Brave) | 사용자 질의 |
| 번역 | `ApiTranslatorManager.cs`, DeepL 비공식 서버 풀 | 발화/응답 텍스트 |
| 스크린샷/클립보드/마이크 | `ScreenshotManager.cs:680-798`, `ClipboardManager.cs`, `STTUtil.cs:320-341` | 화면 전체·클립보드·음성 |

따라서 "수집 안 하니 처리방침 불요"라는 시나리오는 성립하지 않는다. **개인정보처리방침은 확정 필수**이고,
Google(미국)·OpenAI 등으로의 **국외이전 고지(개인정보보호법 제28조의8)** 섹션도 필요하다.

배포 전 제품 측 정리 과제 (약관과 무관하게 필요):
- **하드코딩 Gemini 키 제거** — Google API 약관 위반(키 기밀유지)이고, 무료(Unpaid) 등급은 입력·출력을
  Google이 학습에 사용하므로 그 사실 자체가 고지 대상. 사용자 본인 키 입력 구조로 전환.
- DeepL 비공식 엔드포인트 등 서드파티 약관 위반 경로 교체 검토.
- 로컬 전용 모드와 클라우드 모드의 경계를 방침에 명확히 구분 서술(로컬 처리는 오히려 신뢰 강점).

### 1-3. 게임물 분류 — 스팀 한국 판매의 관문

- AICO가 게임산업법상 '게임물'로 판단되면 수익화 시 등급분류 의무 발생
  (무료·비영리 기간엔 면제, **수익화 순간 면제 소멸**. 미등급 유통은 5년 이하 징역/5천만원 이하 벌금).
- 구글플레이 = 자체등급분류사업자 → IARC 설문으로 자동 해결.
- 스팀 = 자체등급분류사업자 **아님**(2026-07 현재) → 한국 판매 시 GCRB 등급분류를 개발자가 직접
  받아야 하며, 실무 대안은 "등급 완료 전 한국 지역 판매 제외". 2026-10-09 시행 개정법으로 절차 간소화 예정.
- 주의(팩트체크 정정): 스토어 카테고리를 '앱/Software'로 고르는 것은 **법적 면책이 아니다**.
  게임물 여부는 콘텐츠 실질로 판단. AICO는 인연도·상점·미션 등 게임적 루프가 실재하므로 경계 사례 —
  게임물관리위원회 사전 질의(비게임물 확인)가 가장 확실.

## 3. 플랫폼별 요건 체크리스트

### 스팀
- 커스텀 EULA는 선택이나 **AICO는 강력 권장**(에이전트 면책·모델 라이선스 고지는 SSA가 커버 못 함).
  Valve 예시 EULA 참고, SSA와 충돌 불가. 환불은 Valve 14일/2시간 정책 준용 문구만(제한 조항 금지).
- **AI 콘텐츠 공시 필수**: AICO는 'Live-Generated AI' 신고 대상. 가드레일(콘텐츠 필터, 허용 함수 목록,
  위험 명령 차단)을 구체 서술해야 하며, 스토어 페이지에 공개 + 오버레이 신고 버튼 활성화.
  허위·부실 시 스토어 퇴출 가능. 2026-01-16 개정으로 개발 도구(Claude Code 등) 사용은 공시 제외.
- 개인정보처리방침 전용 필드는 없음(팩트체크 정정 — 구글플레이와 다름). 스토어 페이지 링크+앱 내 게시.
- Software 카테고리 등록 가능(수수료 $100 동일). 시스템 제어 기능이 악성 동작으로 오인될 수 있어
  빌드 리뷰 노트에 기능 목적·동의 흐름 설명 필요.
- 한국 판매: 게임물 판정 시 GCRB 등급분류 or 한국 지역 제외(1-3절).

### 구글플레이
- 처리방침 URL(활성 웹페이지, PDF 불가) + Data Safety 폼 — 전 앱 필수, 수집 없어도 제출.
  외부 LLM 전송은 최소 '수집'으로 신고(서비스 프로바이더 관계면 '공유' 신고는 면제 가능 — 정정 반영).
- **AI-Generated Content 정책 직접 적용**(text-to-text 챗봇 중심 앱): 채팅 메시지 단위
  **인앱 신고/플래그 버튼 필수**, 금지 생성물 사전 방지.
- 계정 기능 도입 시 앱 내 삭제 + 웹 삭제 링크 의무. 타깃 연령 13+(권장 16+), 아동 타깃 불가
  (2026-07 정책: 익명 채팅 앱 아동 타깃 금지). Social 카테고리 선택 시 CSAE 표준 문서 의무.
- **에이전트 기능은 모바일 이식 시 AccessibilityService 정책 장벽** — 구글플레이 버전은 기능 축소
  (채팅+캐릭터만) 권장. 모바일 배포 시 정보통신망법 제22조의2 접근권한 고지·동의(필수/선택 구분)도 별도 국내법 의무.
- 수익화: Play Billing 원칙(한국 대안결제 병행 가능, -4%p). 2026-06-30부터 첫 $1M 10% 수수료 체계.
