# Policy 문서 — 근거와 최종 수정 체크리스트

이 폴더의 약관 4종(`PolicyView/Documents/*.txt`)이 **무엇을 근거로 작성됐고**,
배포 전 **사용자가 직접 수정·확정해야 하는 것**이 무엇인지 정리한다.
법령·플랫폼 정책 조사 전문(출처 링크 포함)은 repo 루트 `Docs/LEGAL_TERMS_PLAN.md`.

## 문서의 성격 (중요)

- 임의 창작이 아니다. 2026-07-22 웹 조사(법적 의무·시행일은 별도 팩트체크 검증)와
  AICO 코드 스캔(실제 데이터 흐름 실측)을 근거로 조항을 구성했다.
- 그러나 **AI가 작성한 초안(v0.1)이며 법률 자문을 거친 확정본이 아니다.**
  수익화·스토어 제출 전에 전문가 검토를 권장한다.
